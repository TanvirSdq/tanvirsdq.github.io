Building, Learning, and What Comes Next

First-year CSE student at KUET. Building practical tools, open-source automation, and learning ML foundations.

"If there's a repetitive manual task, a messy dataset, or a real problem students face, I sit down, learn what's needed, and write the code to solve it."

1. Who I Am: Building & Contributing to Open Source

I am currently a first-year undergraduate in Computer Science & Engineering at Khulna University of Engineering & Technology (KUET). My programming journey has always been about learning by building real, useful things.

During my college years at Notre Dame College, Dhaka, as part of the Notre Dame English Club Wikipedia Editorial & Research Team (NDEC WERT), I started writing Python scripts using Pywikibot to automate community operations:

  • Structuring Fulfulde Wikipedia: Wrote automated scripts to categorize and structure roughly 10,000 articles on Fulfulde Wikipedia with core categories mapped from English Wikipedia.
  • Community Contributions: Completed over 46,900 automated bot edits and 6,000+ manual contributions across Wikipedia, Wikidata, and Wikimedia Commons. Served as Category Manager for Wiki Loves Folklore, sorting ~15,800 submissions.
  • CampAnalytics on Wikimedia Toolforge: Built for Project Korikath, CampAnalytics is an analytics tool deployed on Wikimedia Toolforge and Streamlit to track campaign participation and contributor retention.

2. Developer Tooling: Building CodeFunc

I like tools that are lightweight and stay out of the way. When inspecting unfamiliar codebases or checking PRs, jumping between files and documentation creates friction.

To solve that, I built and published CodeFunc (available on the VS Code Marketplace and Chrome Web Store):

  • Line 0 File Summary: Uses VS Code's CodeLens API to show a concise summary and structure at the top of each file without opening side panels.
  • AI Code Explanations: Connects to Gemini, Groq, OpenRouter, and Claude for contextual code breakdowns.
  • Local AST Parsing: Works offline using regex and AST heuristics for instant signature and export analysis.

3. Shipping Under Pressure: CampusShare KUET (Forkathon 2026)

During the 50-hour ForkedArch Freshers Hackathon 2026 (Forkathon 2026), our team secured 1st Place building CampusShare KUET. We tackled a common problem in KUET residential halls: "Does anyone have an Arduino kit or a scientific calculator right now?":

  • Full-Stack Setup: Built an asynchronous FastAPI backend with PostgreSQL on Render, paired with a React 18 web app.
  • Hall Availability Map: Used MapLibre GL to display equipment availability across campus dorms.
  • Handover Verification: A dynamic 6-digit OTP and QR code system ensuring items are verified in person before marking as borrowed or returned.
  • Android App: Packaged the app with Capacitor into an installable Android APK for students.

4. Machine Learning: Learning the Foundations Hands-On

I am actively studying machine learning and data science, aiming to understand what is happening mathematically rather than just calling pre-packaged APIs:

  • AgroScan & Smart Farm: Trained a 38-class plant pathology classifier (crop_disease_model_final.keras) on leaf photos as AgroScan. Contributed the model into production for smart-farm (React + Supabase).
  • From Scratch (MLP-Implementation): Built a character-level Bigram Language Model in PyTorch on The Wizard of Oz text—writing tokenization tables, calculating cross-entropy loss, and sampling text with temperature.
  • Competitions & Coursework: Participating in the University of Tokyo Matsuo-Iwasawa Lab GCI World 2026 program and Kaggle challenges to practice feature engineering and gradient boosting.

5. Where I Am Heading: Systems & Machine Learning

As I move through my CSE coursework at KUET, my goals are:

  • Tokenizers from Scratch: Writing byte-pair encoding (BPE) tokenizers in C/C++ and pure Python to understand tokenization without third-party libraries.
  • Systems Fundamentals: Learning operating systems, memory management, and data structures to write efficient software.
  • Open-Source Tooling: Continuing to build and maintain helpful tools for the Wikimedia community and developers.
